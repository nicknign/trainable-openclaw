# 2026-05-21 — 远程环境搭建

## 项目背景
trainable-openclaw：自进化 Agent 推理服务框架。AI Agent 在对话中收集反馈 → 自动评估打分 → 空闲时 LoRA 微调 → 模型持续进化。基于 veRL 作为推理引擎，目标一个月内完成 MVP（启动 2026-05-16）。

## 目标
在远程 Linux GPU 机器（AutoDL/3090 类）上搭建 trainable-openclaw 运行环境，跑通 `serve_ppo` 推理服务。

## 已完成

### 依赖配置
- `requirements.txt`: 添加核心依赖 (fastapi, uvicorn, httpx, aiohttp, openai, pydantic)
- `verl-main-0516/verl/workers/config/model.py`: 默认 attention 从 `flash_attention_2` 改为 `sdpa`，避免 flash-attn 编译问题导致服务无法启动

### 脚本体系
- `scripts/setup_env.sh` — 完整 Linux 环境安装脚本（venv、PyTorch、veRL、vllm、flash-attn、liger-kernel），支持 CUDA 版本/venv 路径自定义
- `scripts/setup_server.sh` — 服务端一键部署（vllm 0.12.0 + Qwen3-0.6B ModelScope 下载 + 推理测试），含日志记录
- `scripts/run_serve.sh` — serve_ppo 启动脚本（推理服务 + 空闲检测），经过 RTX 4090 24G 验证
- `scripts/check_models.py` — ModelScope 可用模型查询 + VRAM 状态
- `scripts/download_model.py` — ModelScope 模型下载工具
