# trainable-openclaw

## 一句话概述
一个可自进化的Agent推理服务框架——Agent在实际使用中收集对话反馈，自动评估并打分，在服务空闲时进行LoRA微调，实现模型能力的持续自我进化。

## 项目目标
打造一个**生产级**的自进化Agent推理服务，不是研究原型。核心差异化：
1. **基于veRL作为推理引擎**（而非简单的OpenAI API代理）
2. **多维度自动评估**（任务成功率、代码整洁度、用户反馈等rubric打分）
3. **空闲时自动触发训练微调**（资源友好，可在单卡或AutoDL上运行）
4. **工程化、可扩展、有完整文档**

## 初步构想
1. 改造VeRL引擎，转换为推理引擎服务，先提供API服务调用
2. API服务接入openclaw、nanobot等chatbot，进行推理服务+日志收集
3. 做一个简单可视化界面，进行测试时监控
4. VeRL服务引擎使用混合使用资源的形式，rollout阶段提供服务，出现长时间空闲的时候切换到训练模式进行训练
5. 训练完成后切换回推理服务模式，因为verl中已有权重同步步骤，所以只需要训练几步然后停留在rollout阶段即可
6. 有关奖励函数，创建rubiric评价体系，调用deepseek-flash API进行多维度打分
7. 打分原则需要考虑用户反馈，如果出现不对，错误等字眼，即为负反馈信号
8. 需要有日志分析+存储模块，专门处理openclaw、nanobot等智能体的调用，而且能够把冗长的输入进行切分/压缩等；日志记录需要有条理性，按session分开，分用户存储等
